# logo/ — master source

Drop your master orca logo here as **`logo.svg`** (it is currently an empty
placeholder). This is the single source you export every raster variant from.

Brand: a **dark blue / slate field with a red orca**. Colors in `../palette.json`
(`orca_red #e23b3b`, `field_dark #0d1b2a`, `orca_body #1b2b44`).

From this master, export the PNGs into `../assets/logo/` (see `../BRANDING.md`
for the exact file list and sizes). Those `assets/logo/*.png` are the files that
actually ship in the package.
